# JMLR Reproducibility Package v1.0.0

Reproducibility package for:

**Estimation Collapsibility under Markov Equivalence: Chain-Component Structure and Minimal Retained Sets**

This release contains source code, experimental records, random seeds,
software and hardware metadata, benchmark provenance, DSCS timing summaries,
checksums, and manuscript reproducibility material.

Historical experiment Git metadata were not preserved. The Git commit and tag
associated with this public release identify the curated reproducibility
package and must not be described as the historical experiment commit.
